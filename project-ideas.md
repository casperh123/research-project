# Project ideas for the research project




## Thread-safety analysis for data structures with CodeQL (in collaboration with Rasmus Petersen, Engineer @ CodeQL (GitHub)). 
Thread-safe data structures are at the core of any concurrent application. These data structures allow programmers to develop applications without worrying about concurrency issues such as data races. However, checking that the implementation of thread-safe is free from concurrency errors is very challenging. In this project, the goal is to develop CodeQL queries to automatically detect data races in buggy implementations of thread-safe data structures. Ideally, the project should target a programming language with a memory model, but other programming languages with precise thread-safety definitions can be used.
